# BiliSeek

> **Seek and you shall find.** 寻则得之。

一个搜索驱动、以听为主、兼顾视频、**没有推荐和广告**的第三方哔哩哔哩 Android 客户端。

[![License](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)

---

## 这是什么

目前在Android平台有两类 B 站第三方应用：

- **纯音频播放器**（BBPlayer、BiliSound）干净无推荐，但**只能听、不能看**
- **完整客户端**（BiliPai、bilimiao、PiliPlus）能看能听，但**都带推荐首页**、以视频浏览为主

本项目BiliSeek 汲取两者优势，构建全新使用体验

**注意：本项目所有代码均由AI工具开发。本人时间精力有限，未能进行全面细致审查，如有纰漏，请告知。目前仅以个人日常使用需求为开发目标，不定期进行功能完善和开发。如果您希望优化或开发功能，可自行fork魔改。基于此项目的二次开发请遵守GPLv3协议！**

### 核心亮点

1. **全站关键词搜索** —— 打开就是搜索框，**搜遍全 B 站**
2. **以听为主** —— 默认以听为主，**节约个人注意力**
3. **可切看视频** —— 一个按钮切到看模式，**切换无缝**
4. **没有推荐** —— 没有算法推荐流，入口只有搜索 + 个人喜好榜单、行为记录与**关注**

## 特色功能

**搜索与播放**

- 全站搜索，可按时长 / 排序筛选；多 P 视频折叠成一条；BV 号 / av 号 / b23.tv 短链与外部分享直接识别
- 默认只听：后台播放、锁屏与通知栏控制、响度均衡
- 一键切到看模式，不重新加载、不跳进度；支持全屏手势、画中画、弹幕、画质 / 音质选择
- 两层播放队列：手动「加入队列 / 下一首播放」的曲目不会被点击播放冲掉；顺序 / 循环 / 单曲 / 随机、续播、倍速、睡眠定时
- 封面取色驱动播放器配色，深色模式可选

**列表与离线**

- 本地列表（拖动排序、自定义图标）、B 站收藏夹、订阅合集、稍后再看
- 下载音频或视频（断点续传），离线也能播
- 首页一年播放热力图，点开查看当天的收听记录

**账号与互动**（需登录：扫码或用 B 站 App 一键登录）

- 关注动态、UP 主搜索与空间页、关注列表
- 点赞 / 投币 / 收藏 / 评论 / 分享，长按点赞一键三连；评论区与表情
- 消息中心：回复与@、收到的赞、新增粉丝、私信

**AI 视频总结**

- 原文依次取自 B 站官方总结 → 字幕 → 本机离线语音识别（音频不上传）
- 接入你自己配置的 OpenAI 兼容大模型，生成精简 / 详细笔记 / 时间戳大纲等 Markdown；时间戳可点击跳播
- API Key 加密存储；AI 请求不携带 B 站 Cookie

已知问题见 [手动测试指南 · 附录 3](docs/BiliSeek-手动测试指南.md)，后续规划见 [功能优化篇 §10](docs/05-功能优化篇.md)。

## 构建

需要 Android SDK 与 JDK 21+（推荐直接用 Android Studio 自带的 JBR）。

```bash
git clone https://github.com/wym68/BiliSeek.git && cd BiliSeek
echo "sdk.dir=$HOME/Android/Sdk" > local.properties
./gradlew installDebug        # 构建并安装到已连接的设备
./gradlew test                # 单元测试（全离线）
```

- 完整环境配置与排障：[开发环境搭建](docs/01-开发环境搭建.md)
- 正式版构建与发版流程：[发版清单](docs/发版清单.md)
- 参与开发前请先阅读 [AGENTS.md](AGENTS.md)：**自动化测试绝不访问 B 站服务器**，避免账号被风控
