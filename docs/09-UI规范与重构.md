# BiliSeek UI 规范与重构记录

本篇记录 UI 重构（表情渲染、互动按钮统一、视频互动栏）落下的规范与组件，以及需要真人在真机上验收的项。
新页面、新按钮一律按本篇来写，不再各写各的。

## 1. 设计 token（`:design-system` → `theme/Dimens.kt`）

| 类别 | 名称 | 值 | 用途 |
|---|---|---|---|
| 间距 `BsSpacing` | `xxs / xs / sm / md / lg / xl / xxl` | 2 / 4 / 8 / 12 / 16 / 24 / 32 dp | 页面左右边距 `lg`，卡片内边距 `md`，同行元素 `sm`，图标与文字 `xs` |
| 尺寸 `BsSize` | `iconSm / icon / iconLg` | 18 / 24 / 28 dp | 行内图标 / 标准图标 / 竖排互动栏图标 |
|  | `avatarSm / avatar / avatarLg` | 28 / 40 / 64 dp | 评论头像 / 列表头像 / UP 主页头像 |
|  | `touchTarget` | 48 dp | 最小触控区 |
|  | `emoteInline / emoteLarge` | 20 / 48 dp | 行内表情 / 单独大表情 |
| 圆角 `BsShapes` | `xs / sm / md / lg / pill` | 4 / 8 / 12 / 20 dp / 50% | 角标 / 封面、小卡片 / 卡片、楼中楼底板 / 快捷块、设置分组卡片、评论输入框 / 胶囊（Chip、搜索框、`AppToast`） |

新代码不要再写死 `.dp` 和 `RoundedCornerShape(...)`，从上表取。存量页面按页逐步替换。（2026-10-07：`app/` 里仍有 39 处 `RoundedCornerShape(`，分布在 21 个文件，属存量待替换。）

### 2.2 弹窗选型

新弹窗先按用途选型，不再直接写 `AlertDialog` / `DropdownMenu`。2026-10-02 已把存量的统一过来（见功能优化篇 13.36）；2026-10-04 按用户要求，把加入列表和输入框改回屏幕中间（见 13.38）：

| 用途 | 用什么 | 例子 |
|---|---|---|
| 从几项里选（选内容与保存位置、选怎么删） | 底部弹层 `SettingsSheet`，项目用 `SettingsRadioRow` 或整行可点的行；小节标题 `SettingsSheetSection(title, action)`，`action` 槽放标题行右端的按钮（如「新建」） | 下载、删除下载 |
| 加入列表 | 居中弹窗 `CenterDialog`，里面的小节标题和行与底部弹层相同，右下角「取消」（用户要求从屏幕中间弹出）；登录后最上面一行「稍后再看」（时钟图标，没有三点） | 加入列表 |
| 输入文字（新建、重命名） | `InputDialog`（居中） | 新建 / 重命名歌单、新建 / 编辑收藏夹 |
| 确认一件事（尤其是删除） | `BsConfirmDialog`（`destructive` 标红，`busy` 表示动作进行中） | 删除歌单 / 收藏夹、移动网络询问 |
| 「更多操作」菜单、长按菜单 | `ActionListSheet`（以「删除」或「移除」开头的项自动标红配图标） | 三点菜单、总结阅读页的「更多」与版本切换 |
| 轻量提示 | `AppToast`（主界面提示位，在迷你条上方；纯文字的也是，发到 `transientMessage` / `LocalShowMessage`） | 「已取消筛选」「链接已复制」 |

- 底部弹层的拖动条一律用 `CompactDragHandle`（2026-10-04 用户第三次嫌默认横杠留白大，全部统一，见 13.47）。
- 同一个动作在各处菜单里叫同一个名字：「加入列表」「加入队列」「下一首播放」「查看UP主」「复制链接」「下载」「AI 总结」（不再有「添加到列表」「查看作者」「分享」这类别名）。

## 3. 按钮用法规则

| 场景 | 组件 | 例子 |
|---|---|---|
| 页面主操作 | `Button` | 关注、投 N 枚、生成二维码 |
| 次要操作 / 已完成态 | `FilledTonalButton` / `OutlinedButton` | 已关注、新建列表、整页重试 |
| 弹窗与行内的轻操作 | `TextButton` | 取消、合集内容页的「取消订阅」、分页底部重试 |
| 危险操作 | 入口用图标（垃圾桶）或整行红字，确认放进 `BsConfirmDialog(destructive = true)`（确认键是 error 色的 `TextButton`） | 删除收藏夹 / 本地列表（内页顶栏垃圾桶）、退出登录（设置页最下面单独一张红字卡片） |
| 图标操作 | `IconButton`，必须带 contentDescription | 返回、更多操作、清空、发送 |
| 互动计数 | `BsIconAction` | 点赞、评论、转发、投币、收藏、分享 |
| 单选 / 多选项 | `FilterChip` / `SegmentedButton` | 排序、倍速、定时 |

**禁止用字符当图标**（`⋮ › ✕ ⏱ ☰ ▶ ⏸ ✓ ＋ 📁 💬`）：全部改成 Material Icons。图标按钮一律写 contentDescription，UI 测试按描述查找，读屏也能用。

## 4. 富文本与表情

- **切分规则** 在纯函数 `app/ui/richtext/RichTextPolicy.kt` 里（有单测）。在每个位置依次尝试：`[表情]` → `@昵称` → 蓝字关键词 → `#话题#`（只在动态正文里识别）→ `http(s)` 链接，其余都当普通文字。
- **表情来源**：
  - 评论：`content.emote`（容错解码，遇到坏项只丢该项，不会让整页评论解析失败）。
  - 动态：`rich_text_nodes[].emoji`，解析层收集到 `DynamicEntry.emotes`，转发时也包含原动态的表情。
  - 私信：`e_infos`。
  - 进程级字典：`EmoteController.dictionary`，来自表情面板，用来给「回复与@」这类不下发表情表的接口兜底。
- **渲染**：`RichText` 组件。行内表情大小 1.35em、与文字垂直居中对齐；整条内容只有一个大表情时单独放大显示；@ 可点，点了进 UP 空间。
- **输入**：`CommentComposer` 组件，由输入框、表情 / 键盘切换按钮和发送按钮组成，下方可展开表情面板。表情插在光标处；退格时整体删除一个已知表情。评论区、「回复与@」和私信共用这一个组件。
- **请求纪律**：表情面板接口 `x/emote/user/panel/web` 在一个进程里只成功请求一次，结果由仓库层缓存，失败不缓存。只在用户第一次打开表情面板、或进入「回复与@」时触发。

## 5. 视频互动栏（播放页标题下）

参考官方客户端的互动区，竖排「图标 + 数字」，从左到右依次是：点赞 · 投币 · 收藏 · 评论 · 分享 · 总结（AI 总结，这个视频已有本机总结时点亮）。分享显示 B 站的分享数，点了是复制链接。

- **长按点赞 = 一键三连**，与官方手势一致，触发时有强触感反馈。如果已赞、已投满、已收藏，只提示「已经三连过啦」，不再发请求。
- **投币**：点开底部弹层选 1 枚或 2 枚，默认勾选「同时点赞」。转载视频最多只能投 1 枚；已投的枚数会扣掉；投满后只显示提示。
- **收藏**：复用「加入列表」弹窗，可以选 B 站收藏夹，也可以选本地歌单。加入 B 站收藏夹成功后，收藏按钮点亮。
- 评论入口在互动栏里。原先的底栏（播放模式 / 播放列表）已并入播放控制行，见下方「播放页布局」。
- **请求纪律**：
  - 只在播放页展开时，按 bvid 拉一次 `view`（拿计数）和 `archive/relation`（拿互动态，需要登录）。
  - 纯听后台、迷你播放器都不会发这些请求。
  - 同一个 bvid 的结果有 16 条 LRU 缓存。
  - 未登录不请求 relation。
  - 写操作都是乐观更新，失败时回滚；请求进行中按钮处于 busy 状态，防止连点。
- 状态的纯函数在 `app/interaction/VideoActionPolicy.kt`（有单测）。

### 播放页布局：控制行、听 / 看开关与简介

- **布局**（自上而下，2026-10-27 重做，设计稿 `docs/superpowers/specs/2026-10-27-player-layout-and-collection-queue-design.md`）：
  - **顶栏**：左「收起」，正中「听 | 看」开关，右边看模式时是「小窗」+「⋮」，听模式只有「⋮」（纯听本来就能在后台放，不需要小窗）。
  - **封面**（视频画面，16:9）。
  - **中段**占满封面与底部块之间的高度，顺序：标题 → 互动栏 → 合集卡片（视频属于合集才有）→ 简介行 → 简介预览。标题到简介行按自然高度排，剩下的高度都给简介预览（`VideoDescriptionPreview`）：能放几行放几行（`VideoDescriptionPolicy.previewLines`），最后一行末尾省略号，放不下一行就不画；纯文字，点一下打开全文弹层；简介为空时没有预览。正常屏幕上中段不滚动；屏幕特别矮、标题到简介行放不下时，预览缩到 0 行，这几行改成可上下滑（`TopThenFillColumn`），不会被挤扁。换视频时中段整块重建。
  - **状态标签**（`PlayerStatusChips`）：进度条上方，只在调过倍速、设了定时时出现，都没设时这一行不画。
  - **进度条 + 控制行**沉在页面底部。
- **小画面（看模式）**：播放中长按画面临时加速、松手恢复（2×，在放无损时 1.5×；暂停时不响应），开始时震一下、画面中间显示黑底「2.0× 加速中」——与全屏同一套（`LongPressSpeedBoost`，规则 `resolveLongPressSpeed`）。听模式的封面不响应长按。
- **离开播放页**（收起箭头、系统返回、点底部页面、查看UP主）都走 `leavePlayerThen`：在看就先 `PixelCopy` 截下当前一帧顶替画面（同位置、8dp 圆角），再切成听、再弹出，整页连同这一帧一起淡出。播放页的 `BackHandler` 注册在 PLAYER 路由里——放在 NavHost 外面会被它内部的返回处理抢先（后注册的优先），视频在退场动画里一直盖着（2026-10-04，功能优化篇 13.61）。
- **控制行**（`PlayerPageControlRow`）：「播放模式 · 上一首 · 播放 · 下一首 · 播放列表」五个按钮等间距一行，左右宽度对称（48 / 56 / 72 / 56 / 48dp），播放键正好在屏幕中线。
- **播放键**：实心圆底加深色图标，播放态用不带圆圈的三角，避免「圆里套圆」。全屏控制层共用同一个按钮。
- **播放模式按钮**：四种模式四个图标——顺序播放灰色向右箭头，列表循环 / 单曲循环 / 随机播放主色（`Repeat` / `RepeatOne` / `Shuffle`）；每次切换弹一条只写模式名的提示，连点只显示最新一条。模式顺序与名字在 `PlayModePolicy.kt`（有单测），设置页的选项共用同一份名字。
- **听 | 看开关**（`ListenWatchSwitch`，顶栏正中，高 32dp）：分段胶囊，选中的一段填主色、另一段灰；点已选中的一段不做事。「听」用耳机，「看」用自绘的小电视（`WatchTvIcon`）。
- **倍速 / 定时状态标签**（`PlayerStatusChips`，进度条上方）：调过倍速写当前档位（`1.5×`，`speedButtonLabel`），设了定时写剩余时间（`28:40`）或「播完当前」（`sleepTimerChipLabel`），都是主色小胶囊；点开对应的倍速 / 定时弹层。没设的那个不显示。胶囊高 32dp、点击区 48dp。
- **三点菜单**（`PlayerMoreMenuSheet`）：顶部三个方块「查看UP主 / 加入列表 / 下载」，下方「倍速 / 定时 / 画质（有可选画质时）/ 音质 / 复制链接」。倍速、定时设了值时右边写当前值（主色，和上面的标签同一写法），没设不写。一打开就完整展开（不先停在半屏），刚好显示到最后一项。倍速、定时只从菜单和状态标签进（2026-10-04 曾从菜单去掉、只留页面上两个常驻胶囊，见 13.47；2026-10-27 胶囊改成设了值才出现，入口回到菜单）。
- **简介行**（`VideoDescriptionRow`）：左边「简介 展开」、右边「播放 52.1 万 · 3天前」。有内容时「简介」是普通字色的标签，旁边「展开」+ 18dp 下箭头用链接色，两者一块点击区（至少 40dp 高），点开底部弹层（`VideoDescriptionSheet`，外壳 `SettingsSheet`，高度随内容）看全文，可滑动、可长按选择复制；没内容（含 B 站常见的单个 `-`）时「简介」「展开」都不显示，只剩统计行（靠左）；行高至少 40dp，有没有简介进度条都不跳；简介和统计都没有（本地文件、详情未加载）时整行不显示（2026-10-04 改，见功能优化篇 13.58）。
  - 弹层里时间点（`05:12`、`1:02:03`）可点，点了跳到该处并接着播，超过当前分 P 时长的不可点；点了之后弹层自动收起。
  - BV / av 号和 `bilibili.com/video/…` 链接在应用内播放；`b23.tv` 短链点了才展开，落点是视频就应用内播放，否则交给浏览器；其余网址交给浏览器。
  - 切分规则是纯函数 `app/ui/VideoDescriptionPolicy.kt`（有单测）。
- **请求纪律**：简介、播放量、发布时间都出自互动栏那次 `view` 请求，不额外发请求。只有点 b23 短链时才发一次展开请求。

### 5.1 首页快捷入口与设置页入口（2026-10-21，规则见 `docs/superpowers/specs/2026-10-21-home-quick-entries-design.md`）

- **首页**：快捷入口每行 4 张卡片，自动换行；卡片样式、高度不变。最后一行不足 4 张时靠左，空位用等宽占位撑住，卡片宽度不变。入口全部关掉时整个「快捷入口」一节不显示。
- **入口清单（默认顺序，全部默认开启）与图标**（Material Icons Outlined）：

| 入口 | 稳定 id | 图标 |
| --- | --- | --- |
| 每周必看 | `weekly` | `CalendarMonth` |
| 入站必刷 | `precious` | `Whatshot` |
| 热歌榜 | `hot_songs` | `Leaderboard` |
| 原创音乐榜 | `original_songs` | `MusicNote` |
| 热门播客 | `podcast` | `Podcasts` |
| 视频播客 | `video_podcast` | `Mic` |
| 全站排行榜 | `ranking` | `EmojiEvents` |
| 分区（2026-10-21 新增，第二期，默认开） | `regions` | `Category` |
| 子分区（22 个，默认关） | `region:<tid>` | 所属大类图标：音乐 `LibraryMusic`、知识 `School`、纪录片 `Movie`、杂谈 `Forum`、配音与广播剧 `RecordVoiceOver` |

子分区入口只有在入口设置页里打开后才出现在首页；`QuickEntry` 是密封接口（`FixedQuickEntry` + `RegionQuickEntry`），设置里缺少的入口按各自默认值追加在末尾。

- **设置页**：「界面」分组新增「首页快捷入口」一行，值显示「显示 N 个」，点开进入入口设置页。
- **入口设置页的行结构**：左起图标、名字、开关、拖动手柄；整行点一下切换开关，长按整行拖动换顺序（通用 `DragReorderState`，`ui/DragReorder.kt`，本地列表拖动排序共用）。设置存 DataStore 键 `home_quick_entries`，格式 `id,-id`（`-` 开头表示关）；不认识的 id 丢弃，新增入口追加在末尾，开关按各入口的出厂默认值（「分区」开，子分区关）。
- **首次提示**：`HintKey.HOME_QUICK_ENTRIES`，气泡「入口可以在 设置 → 首页快捷入口 里关闭和排序」，无手势动画，碰一下或约 4 秒后消失。

### 5.2 分区入口三个页面（2026-10-21，规则见 `docs/superpowers/specs/2026-10-21-region-entries-design.md`）

- **分区总览**（`RegionOverviewScreen`）：顶部一张时间卡片（显示当前时间范围，点开时间弹层）；下面是 5 张大类卡片，卡片里是该大类的子分区 `AssistChip`，点芯片进分区详情并停在该子分区。返回回首页。
- **分区详情**（`RegionDetailScreen`）：顶栏标题为大类名，右侧排序菜单（播放 / 收藏 / 硬币 / 弹幕 / 评论，与时间弹层共用）；下面一行 `ScrollableTabRow` 子分区标签，`HorizontalPager` 横滑切换；列表上方一行显示时间范围（点开时间弹层）和「隐藏 1 分钟以下」开关。列表行与榜单页同款（`ChartRow`），到底自动续页；没有可见条目且没有更多页时显示空状态，提示关掉「隐藏 1 分钟以下」。从总览进则返回回总览，否则回首页。
- **时间弹层**（`RegionTimeSheet`，底部弹层，窄横杠）：分段按钮三选一（最近 7 天 / 按月份 / 自定义）；按月份时是年月选择（未来的月份不可选）；自定义时嵌 `DateRangePicker`（含首尾不超过 30 天，不早于 2009-01-01，不晚于今天），不合规时「完成」不可点并提示原因；排序用一排 `FilterChip`；底部「完成」。

## 6. 真机验收清单（真人执行，Agent 不访问 B 站）

1. **评论表情**：打开一个评论多的视频的评论区，确认：
   - `[doge]` 这类表情显示成图片，而且和文字对齐；
   - 只有一个大表情的评论会放大显示；
   - @ 高亮，点击能进 UP 空间，同时评论弹层关闭；
   - 蓝字关键词高亮。
2. **楼中楼**：楼中楼里的表情正常显示；「查看全部 N 条回复」→「加载更多回复」这条路径正常。
3. **动态表情和话题**：动态正文里的表情、`#话题#` 高亮正常；转发动态里原动态的表情也能显示；「…展开 / 收起」正常。
4. **表情面板**：
   - 评论输入栏点表情按钮后键盘收起、面板展开；
   - 表情插在光标处；
   - 退格时整体删除一个表情；
   - 切换表情包 tab 正常；
   - 颜文字包以文字网格显示；
   - 发送后面板收起。
5. **「回复与@」**：点条目弹出消息详情（全文、被回复的评论、视频与「播放视频」、回复框），回复弹层里可以用表情；点条目本身不播放（2026-10-21 起，原长按回复已去掉）。列表里的常用表情通过字典兜底显示。
6. **私信**：文字消息里的表情显示正常；图片消息、大表情消息直接显示图片；输入栏可以用表情。
7. **视频互动栏**：
   - 计数显示格式正确（例如 `1.2万`）；
   - 已赞、已投币、已收藏的状态和官方 App 一致；
   - 点赞 / 取消点赞正常；
   - 投币弹层：转载视频只能选 1 枚、投满后只显示提示；
   - 长按点赞触发三连；
   - 收藏走「加入列表」弹窗，加入 B 站收藏夹后收藏按钮点亮；
   - 未登录时点赞会提示「请先登录」；
   - 纯听状态锁屏时，抓日志确认没有 `archive/relation` 请求。
8. **按钮统一**：
   - 各二级页面左上角都是返回箭头；
   - 各处「更多操作」都是图标，不再是 `⋮` 字符；
   - 迷你播放器的播放 / 暂停 / 列表按钮都是图标；
   - UP 空间：未关注时是「+ 关注」按钮，已关注时是「✓ 已关注」按钮（次要样式）。
