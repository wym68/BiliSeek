## 真机反馈驱动的改动（按时间）

| 反馈 | 处理 |
| --- | --- |
| 模型名不知道怎么填 | 文档与提示说明（以平台文档为准，本项目不设默认模型名） |
| 阅读页标题过大、头部信息挤成一行 | 阅读页专用的紧凑排版；头部元信息一项一行，链接缩成 BV 号 |
| 等待页与状态栏重叠 | 阅读页 / 分 P 选择页补系统栏避让 |
| 重新生成会覆盖旧总结 | 改为多版本：可切换、单删、全删（DB v6 → v7 + 迁移） |
| 时间戳点击在暂停时只跳不播 | `PlayerConnection.seekAndPlay` |
| 播放页看不出是否已总结 | 「总结」按钮已总结态（实心 + 主题色） |
| 动作菜单没有图标、拖动条占高 | 图标、窄拖动条、标题单行 |
| 想看到有哪些总结并清理空间 | 「播放列表」页里的「AI 总结」本机列表（占用空间、进入、删除、清空） |
| 官方总结总是抢占默认选择 | 设置「默认选择」加入 B 站总结，弹窗默认按设置，手动点选不被查询结果覆盖 |
| 阅读页改成弹窗并可上拉撑满 | 自写可拖动底部面板（M3 半展开高度固定为一半、不可调） |

## 未验证 / 已知欠账

- **第三方行为未验证**：MiniMax 错误码表、官方总结接口字段、HuggingFace 模型下载地址与官方包是否逐字节一致（不一致时校验失败，可手动导入）、R8 下各功能的长期稳定性。
- **离线识别速度**：默认 RTF 0.1 只是保守估计，待真机实测校准。
- **自动化测试欠账**：`SummaryManager`、阅读页 / 弹窗 UI、`PcmDecoder`、`LocalAsrSource` 状态测试、官方总结「风控码只请求一次」的仓库层测试；`AiSettingsStore` / `KeystoreCipher` 等仪器化测试未写（详见工单 §5.1 / §8）。
- **数据库升级**：v5 → v6 → v7 的迁移有仪器化测试用例（需设备 / 模拟器运行），release 包是全新安装，未在真实升级路径上跑过。
- release 包与 debug 包包名不同，可并存；debug 包里生成的总结不会出现在 release 包里。
