## 4. 途中抓到并修掉的坑（按价值排序）

1. **`arc/search` 的时长字段是 `length`（"03:53" 文本）不是 `duration`（秒）**——首版 UI 全部显示 00:00，真机化验证时发现。这是 DTO 字段名与接口文档的偏差，单测已钉住。
2. **UP 模式无关键词时显示「没有找到相关 UP 主」**——应与视频模式一致回首页空状态（搜索历史/最近播放），已修。
3. **动态头像没走 `normalizeCoverUrl`**——`//i0.hdslb.com` 无协议前缀，已修（单测捕获）。
