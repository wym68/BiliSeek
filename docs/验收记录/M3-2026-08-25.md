## 发现并修复的缺陷

### 1. SurfaceView 父容器冲突导致崩溃（阻断性）

**现象**：从全屏返回展开态时 App 直接崩溃，重启后状态复位——表现为「按两次返回就退出应用」，极易误判成 `BackHandler` 失效。

**根因**：

```
FATAL EXCEPTION: main
  at android.view.ViewGroup.addViewInner(ViewGroup.java:5256)
  at androidx.compose.ui.viewinterop.AndroidViewHolder.<init>
```

同一个 `SurfaceView` 实例被两个 `AndroidView` 宿主持有——展开态的视频区与全屏 overlay 各有一个。**一个 View 只能有一个父容器。**

**修复**：抽出 `PlayerSurface`，在 `factory` 里先从旧父容器摘除：

```kotlin
AndroidView(factory = {
    (surfaceView.parent as? ViewGroup)?.removeView(surfaceView)
    surfaceView
})
```

复用同一个 SurfaceView 而非各建一个，是为了保持 surface 连续——重建会让画面闪断，破坏「无缝」。

### 2. 清空搜索框不回到首页空状态

清关键词后结果列表仍在，首页空状态永远看不到。改为关键词清空时一并重置搜索状态。

### 3. 播放历史存了未清洗的原始标题

`onResultClick` 直接把带 `<em class="keyword">` 的原始标题入库。修为入库前走 `stripHighlight`。

## 一次测试方法上的自我纠错

A-3 首次验证时判定「BackHandler 失效」——实际是**测试步骤有问题**：`force-stop` 后没有播放内容，MiniPlayer 因 `AnimatedVisibility` 不可见，点击落空，`expansion` 始终是 `COLLAPSED`，BackHandler 本就处于禁用状态。

加日志后重测（先起播再展开）确认功能正常。**排查 UI 问题时，先确认前置状态真的建立了。**
