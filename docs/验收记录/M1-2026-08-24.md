## 发现并修复的缺陷

### `AuthGate.awaitReady()` 在凭据失败时无限挂起

**现象**：断网时点播放，界面「取流中…」永远转下去，既无错误提示也无恢复路径。

**原因**：

```kotlin
// 错误写法
return state.first { it is AuthState.Ready }
```

重试预算耗尽后状态停在 `Failed`，`first { it is Ready }` 的条件永远不成立，调用方协程无限挂起。

**修复**：失败时抛异常而非继续等待，并让每次调用重新触发一轮 `ensureReady`，使网络恢复后可自愈。

```kotlin
ensureReady()
return when (val s = state.value) {
    is AuthState.Ready -> s.credentials
    is AuthState.Failed -> throw IllegalStateException("风控凭据不可用：${s.reason}")
    else -> throw IllegalStateException("风控凭据未就绪")
}
```

修复后断网点播放会明确报错，网络恢复后再点即可正常起播（A-5 已验证）。

## 工具经验

**uiautomator dump 无法解析含双引号的文本。** 错误消息 `Unable to resolve host "api.bilibili.com"` 里的双引号会破坏 XML 属性，导致基于正则的解析拿不到该节点——一度误判为「AuthCard 没渲染」。**遇到文本相关的疑似 UI 缺陷，先用 `screencap` 截图确认**，别只信 dump。
